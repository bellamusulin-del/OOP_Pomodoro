# OOP_Pomodoro

Ez a projekt egy Java nyelven megírt, Asztali Pomodoro-óra alkalmazás, amely a klasszikus időgazdálkodási módszerre épül: 25 perc fókuszált munkát 5 perc rövid szünet követ, négy teljes ciklus után pedig egy hosszabb pihenőidőszak következik. A szoftver fejlesztése során kiemelt szempont volt a tiszta architektúra, így az alkalmazás a Model-View-Controller (MVC) és az Observer (megfigyelő) tervezési mintákat követi. Ennek köszönhetően a pomodoro.model csomagban található üzleti logika és állapotkezelés teljesen független a grafikus felülettől, egyetlen javax.swing importot sem tartalmaz.   A felhasználói felület a Swing keretrendszerre épül, és teljesen egyedi megjelenést kapott: domináns rózsaszín (hot pink) vizuális témával, lekerekített egyedi gombokkal (RozsaGomb) és aranyos képi kabalákkal teszi élvezetessé a használatot. Az alkalmazás felülete nemcsak tetszetős, hanem funkcionálisan is gazdag. Magában foglal egy külön beállítások ablakot (BeallitasokDialog), egy testreszabott statisztikai panelt (StatisztikaPanel), amely saját paintComponent metódusával rajzolja ki a napi teljesítményt egy oszlopdiagramon, valamint támogatja a rendszertálcára való kicsinyítést is, ahol a tálcaikonon folyamatosan nyomon követhető a hátralévő idő.   A funkcionalitást több hasznos kényelmi funkció is kiegészíti. A munkafázisok és a szünetek közötti váltáskor a rendszer automatikus hangjelzést ad a felhasználónak (Toolkit.beep()). A megtett munkamenetek adatait az alkalmazás automatikusan elmenti a statisztika.txt fájlba, így a korábbi teljesítmények bármikor visszakövethetők és elemzhetők a Statisztika gombra kattintva. A projekt háttérrendszere teljesen fel van készítve a gyors fejlesztésre és tesztelésre: az osztálydiagram a docs/osztalydiagram.puml fájlban található PlantUML formátumban, míg az UI működését a docs/screenshots/ mappában lévő képernyőképek szemléltetik.   A projekt futtatásához mindössze JDK 17 vagy újabb Java környezetre és Apache Maven build eszközre van szükség. A program egyszerűen elindítható parancssorból az mvn compile exec:java paranccsal, de tetszőleges fejlesztői környezetből (például NetBeansben a Fo.java fájlra kattintva a Run File opcióval) is futtatható. A kód minőségét és a logikai folyamatok hibátlan működését 17 darab UI-független JUnit 5 unit teszt garantálja, amelyek az mvn test paranccsal futtathatók le.
