# OOP_Pomodoro

This project is a Java-based desktop Pomodoro timer application built around the classic time-management technique: 25 minutes of focused work followed by a 5-minute short break, with a longer break after four full cycles. Clean architecture was a primary focus during software development, so the application adheres to the Model-View-Controller (MVC) and Observer design patterns. As a result, the business logic and state management located in the pomodoro.model package are completely independent of the graphical user interface, containing zero javax.swing imports.   The user interface is built on the Swing framework and features a fully customized appearance: a dominant hot pink visual theme, custom rounded buttons (RozsaGomb), and cute image mascots to make usage enjoyable. The application interface is not only visually pleasing but also functionally rich. It includes a dedicated settings dialog (BeallitasokDialog), a customized statistics panel (StatisztikaPanel) that draws daily performance as a bar chart via its overridden paintComponent method, and support for minimizing to the system tray, where the remaining time can be continuously tracked on the tray icon.   Functionality is augmented by several practical convenience features. When transitioning between work phases and breaks, the system provides an automatic sound notification (Toolkit.beep()). Completed session data is automatically saved to the statisztika.txt file, allowing past performance to be reviewed and analyzed at any time by clicking the Statistics button. The project backend is fully prepared for rapid development and testing: the class diagram is available in PlantUML format in docs/osztalydiagram.puml, while UI functionality is illustrated by screenshots in the docs/screenshots/ folder.   Running the project requires only a Java Development Kit (JDK 17 or higher) and the Apache Maven build tool. The application can be easily launched from the command line using the command mvn compile exec:java, or executed directly from any IDE (for example, in NetBeans by clicking on Fo.java and selecting the Run File option). Code quality and the flawless operation of logical flows are guaranteed by 17 UI-independent JUnit 5 unit tests, which can be executed using the command mvn test
